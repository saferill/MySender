# MySender

share files locally without internet. fast, p2p, encrypted, no tracking.

## download

grab the binaries from [releases](https://github.com/saferill/MySender/releases/latest).

- **windows**: installer (.exe) / portable (.zip)
- **android**: apk (arm64 / armv7 / x86_64 / universal)
- **linux**: standalone (.tar.gz)

## features

- direct p2p wifi transfer (no server needed)
- end-to-end encryption (tls/https)
- web send (share to browser via link/qr)
- cross platform (android, windows, linux, macos, ios)
- no ads, no telemetry

## dev

```bash
# get deps
cd app
fvm flutter pub get

# run
fvm flutter run
```
